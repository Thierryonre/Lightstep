Supplementary Code 1: filament_3D_17nc.py

This Python script generates the three-dimensional filamentary density distribution used for the 17 nc foam-target PIC simulations. The code constructs stochastic filament structures in the target region by using three-dimensional random walks. The accumulated filament field is smoothed and then mapped to a positive truncated Gaussian distribution. The final electron density is normalized so that the mean target density becomes 17 nc. The electron density is then decomposed into proton, carbon, and oxygen ion densities according to the target composition. The generated density arrays are saved as binary files in the format used by EPOCH. The script also outputs diagnostic figures, including density histograms, two-dimensional density slices, three-dimensional point-cloud plots, and three-dimensional box-surface visualizations.

Supplementary Code 2: filament_3D_high.py

This EPOCH input deck defines the three-dimensional PIC simulation for the 17 nc filamentary foam-target case. The simulation domain is -10 < x < 190 um and -10 < y,z < 10 um, resolved by 2500 x 250 x 250 cells. The laser has a wavelength of 0.81 um, a pulse duration of 45 fs, a focal spot size of 1.6 um FWHM, and a peak intensity of 5.48 x 10^21 W/cm2. The plasma consists of electrons, protons, carbon ions, and oxygen ions, and their initial density profiles are read from the binary files generated by filament_3D_17nc.py. The initial electron and ion temperatures are set to 10 keV. The output includes electromagnetic fields, particle momenta, particle energies, number densities, and rolling restart files.

Supplementary Code 3: input.deck

This Python script generates a local-dense filamentary density distribution for the PIC simulations. The basic procedure is the same as in filament_3D_17nc.py, but this version introduces biased filament injection into a selected high-density region. The focus region is defined as 0 < x < 10 um, |y| < 4 um, and |z| < 4 um. A fraction of the filament starting points is placed inside this region, while the remaining filaments are initialized uniformly in the full target region. This produces a locally enhanced density structure near the laser interaction region while keeping the overall density normalization controlled by the prescribed final_scale_nc parameter. The code saves the resulting electron, proton, carbon, and oxygen density profiles as EPOCH-readable binary files and also outputs diagnostic plots. The script additionally calculates the mean density in the high-density focus region and in the surrounding target region, which is useful for confirming the local overdense condition.
